How It Works

AI scoring based on public GitHub signals and code quality metrics

Data Sources

Our engine ingests GitHub repository metadata, commit history, pull requests, issues, stars, forks, and package metadata.

Scoring System

  • Stars & Forks: popularity signal.
  • Commits: activity consistency.
  • Code quality: lint checks, test coverage, README score.
  • Community: issues, PRs, documentation.

Transparency

Scores are based on stars, forks, commits, and code quality. We compute a normalized score from 0-100 and provide actionable recommendations.

Usage

This is an advisory tool to help developers and recruiters evaluate portfolio readiness; not a final job decision metric.
