About PortIQ

How the evaluation works

What is PortIQ?

PortIQ is a multi-profile career evaluation tool that analyzes GitHub repositories, Resume PDFs, LinkedIn profiles, and personal portfolio websites to give developers and students a clear picture of where they stand and how to improve.

GitHub Repo Analysis
Resume ATS Scoring
LinkedIn Optimization
Portfolio Evaluation

How Each Evaluation Works

GitHub

Pulls live data from the GitHub API — stars, forks, commits, PRs, README coverage, test presence, language diversity.

score = stars×0.3 + forks×0.2 + repos×2 + recent_push×3 + readme×5 + tests×5 + commits×0.1 + prs×0.5
Resume

Extracts PDF text, detects 20+ skills, checks for key sections, scores ATS compatibility 0–100.

LinkedIn

Headline formula, profile completeness, visibility SEO, networking strategy — all based on best practices.

Portfolio Site

Checks sections (About, Projects, Skills, Contact), HTTPS, meta tags, GitHub link, page weight.

Scoring & Transparency

  • GitHub data fetched live from public GitHub API — no scraping.
  • Resume analysis is rule-based — no data stored or sent externally.
  • LinkedIn tips are best-practice based — no LinkedIn API needed.
  • Portfolio analysis uses URL content heuristics only.
  • Same inputs always produce the same score.
