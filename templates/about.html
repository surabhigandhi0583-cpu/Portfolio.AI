About PortIQ

How our AI evaluates your career profile — transparently.

What is PortIQ?

PortIQ is a multi-profile career evaluation tool that analyzes GitHub repositories, Resume PDFs, LinkedIn profiles, and personal portfolio websites to give developers and students a clear picture of where they stand and how to improve. Think of it as your AI career coach, available 24/7.

How Each Evaluation Works

GitHub Evaluation

Pulls live data from the GitHub API across all public repositories:

  • ⭐ Stars, forks, commit count & pull request history
  • 🗓 Recent activity — repos pushed in the last 90 days
  • 📖 README coverage & test directory presence
  • 🌐 Language diversity across all repositories
score = stars × 0.3 + forks × 0.2 + repos × 2 + recent_push × 3 + readme × 5 + tests × 5 + commits × 0.1 + prs × 0.5
Resume Evaluation

Extracts text from your PDF and applies rule-based ATS analysis:

  • Detects 20+ technical skills by keyword matching
  • Checks for Education, Experience, Projects, Achievements, Contact, Summary sections
  • Scores ATS compatibility 0–100 based on section completeness & skill density
  • Generates targeted improvement recommendations
LinkedIn Evaluation

Provides structured profile improvement guidance based on LinkedIn best practices:

  • Personalized headline writing formula
  • Profile completeness tips (photo, about, projects, education)
  • Visibility & SEO optimization (Open to Work, skill endorsements)
  • Networking strategy for connecting with recruiters & peers
Portfolio Website Evaluation

Analyzes your personal portfolio site for professional readiness:

  • Checks for key sections: About, Projects, Skills, Contact, Resume link
  • Evaluates content clarity, call-to-actions, and first impression
  • Scores portfolio quality and highlights what to add
  • Gives design & structure recommendations

Scoring & Transparency

  • All GitHub data is fetched directly from the public GitHub API — no scraping.
  • Resume analysis is rule-based (no data stored or sent to third parties).
  • LinkedIn tips are pre-computed best practices — no LinkedIn API access needed.
  • Portfolio analysis uses URL content heuristics only.
  • Scores are reproducible — same inputs → same score every time.
